# 📊 Exploratory Data Analysis (EDA) App

An interactive EDA web app built with Python and Streamlit that lets users upload any CSV file and instantly explore their data through automated analysis and visualizations.

🔗 **Live App**: https://analysiseda.streamlit.app

---

## 🚀 Features

- **CSV Upload** — Upload any CSV file and get instant analysis
- **Dataset Overview** — View raw data, shape (rows × columns), and column types
- **Statistical Summary** — Auto-generated descriptive statistics for all numeric columns
- **Distribution Plots** — Interactive histograms with KDE curve for any column
- **Boxplots** — Identify outliers and spread for any numeric column
- **Missing Value Analysis** — Detect and visualize missing data
- **Column-wise Exploration** — Select any column to explore individually

---
